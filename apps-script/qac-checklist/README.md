# QAC Checklist System (Document In & Out)
### Sovannaphumi School 25, Takeo Campus (សាលារៀនសុវណ្ណភូមិទី25 ទីតាំងខេត្តតាកែវ)

This directory contains the complete source code for the standalone Google Apps Script QAC Checklist web application with multi-year partitioning (Academic Years 2025 - 2035).

## Files:
- `Code.gs`: Backend script handling Drive year subfolders, PropertiesService progress by year, and authentication.
- `Index.html`: Frontend layout with year selector dropdown and responsive UI.
- `Css.html`: Styles and design tokens.
- `JavaScript.html`: Department checklist data, reactive progress calculation, and Google Apps Script RPC handlers.
